AideTalk 위젯 데모

우하단 런처는 Shadow DOM 안에서 렌더링되어 호스트 페이지 스타일과 격리됩니다. 아래 본문은 스크롤/전환 트래킹 테스트를 위한 더미 콘텐츠입니다.

기본값: workspaceId=ws_demo, server=http://localhost:4000

쿼리로 변경 가능: ?ws=ws_xxx&server=http://localhost:4000

트래킹 클릭 테스트: URL에 ?at_l=tlk_test 를 붙이면 로더가 POST /t/click 를 발사하고 파라미터를 제거합니다. (데모 진입점은 로더를 쓰지 않으므로 트래킹은 실제 로더 빌드에서 확인)

데모는 로더(widget.js)를 거치지 않고 본체를 직접 마운트합니다. 로더/본체 분리 빌드는 pnpm --filter @aidetalk/widget build 산출물을 참고하세요.
